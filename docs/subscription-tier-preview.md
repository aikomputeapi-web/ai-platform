# Subscription Tier Preview

## Goal

Update the landing page and pricing page to present subscription tiers that match Anthropic's tier structure and usage limits, with revised lower prices.

This preview is intentionally aligned to the current product positioning:

- only mention **Anthropic** and **OpenAI** models;
- use **Claude 4.7 Opus** and **Claude 4.6 Sonnet** as the Anthropic model names;
- use **GPT-5.5** as the latest OpenAI model name.

## Research Summary

Anthropic's current subscription packaging is effectively represented as three paid tiers:

### Claude Pro

- **Price:** about **$20/month**
- **Usage limits:**
  - 5-hour window: about **50-100 requests/messages**
  - daily: about **100-200 requests/messages**
  - weekly: about **500-700 requests/messages**
  - monthly: about **2,000-3,000 requests/messages**
- **Model access:** Claude 4.6 Sonnet, Claude 4.7 Opus, and related Claude models
- **Behavior:** priority access during busy periods

### Claude Max 5x

- **Price:** about **$100/month**
- **Usage limits:**
  - 5-hour window: about **100-200 requests/messages**
  - daily: about **200-400 requests/messages**
  - weekly: about **1,000-1,400 requests/messages**
  - monthly: about **4,000-6,000 requests/messages**
- **Model access:** all Claude models, including Claude 4.7 Opus and Claude 4.6 Sonnet
- **Behavior:** higher priority access and larger usage envelope than Pro

### Claude Max 20x

- **Price:** about **$200/month**
- **Usage limits:**
  - 5-hour window: about **200-400 requests/messages**
  - daily: about **400-800 requests/messages**
  - weekly: about **2,000-2,800 requests/messages**
  - monthly: about **8,000-12,000 requests/messages**
- **Model access:** all Claude models, including Claude 4.7 Opus and Claude 4.6 Sonnet
- **Behavior:** highest priority access and extended context benefits

## Proposed Product Tiers

### Pro

- **Price:** **$5/month**
- **Equivalent to Anthropic:** Claude Pro at 75% off
- **Same limits:**
  - 50-100 requests/messages per 5-hour window
  - 100-200 requests/messages per day
  - 500-700 requests/messages per week
  - 2,000-3,000 requests/messages per month
- **Included models:**
  - Claude 4.7 Opus
  - Claude 4.6 Sonnet
  - GPT-5.5
- **Positioning:** entry plan with the same quota envelope, lower price, broader provider access

### Max 5x

- **Price:** **$25/month**
- **Equivalent to Anthropic:** Claude Max 5x at 75% off
- **Same limits:**
  - 100-200 requests/messages per 5-hour window
  - 200-400 requests/messages per day
  - 1,000-1,400 requests/messages per week
  - 4,000-6,000 requests/messages per month
- **Included models:**
  - Claude 4.7 Opus
  - Claude 4.6 Sonnet
  - GPT-5.5
- **Positioning:** mid-volume plan with higher priority routing and a larger usage envelope than Pro

### Max 20x

- **Price:** **$50/month**
- **Equivalent to Anthropic:** Claude Max 20x at 75% off
- **Same limits:**
  - 200-400 requests/messages per 5-hour window
  - 400-800 requests/messages per day
  - 2,000-2,800 requests/messages per week
  - 8,000-12,000 requests/messages per month
- **Included models:**
  - Claude 4.7 Opus
  - Claude 4.6 Sonnet
  - GPT-5.5
- **Positioning:** highest-volume plan, highest priority routing, broader OpenAI + Anthropic coverage

## Landing Page Preview

### Hero copy

The hero should communicate the value proposition directly:

> One OpenAI-compatible endpoint. Automatic failover, cost-optimized routing, and real-time model health — now with Pro subscriptions at a lower price than Claude Pro.

### Trust strip

The provider strip should only reference:

- Anthropic
- OpenAI

### Stats callout

A pricing-oriented stat can replace or augment the existing savings stat:

- **75% cheaper**
- **Same limits**
- **Claude 4.7 Opus + Claude 4.6 Sonnet + GPT-5.5**

### Pricing teaser section

The landing page should show four tiers:

- **Free** — introductory access
- **Pro** — $5/month
- **Max 5x** — $25/month
- **Max 20x** — $50/month

Each paid tier should visually compare against Anthropic's equivalent price using a strikethrough price:

- Pro: `$5` vs `$20`
- Max 5x: `$25` vs `$100`
- Max 20x: `$50` vs `$200`
